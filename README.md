A drop-in replacement for makefun-site 1.0.0 that builds the same static sites byte-for-byte, about four times faster. It is a dependency-free Node.js module: hand-tuned scanners for front matter, Markdown and templates replace the reference implementation's regex passes, and repeated work across pages is cached.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
